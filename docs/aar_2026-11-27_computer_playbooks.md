# Computer teams and the Playbook Cookbook

College and Dynasty setup offer an opt in for computer teams to use saved books. An all computer college season can use it with no team selected. For each school and side, roughly half of the teams with a fitting book draw one from the library. A book must match the team’s school and have at least one package that fits its roster. Computer coordinators use the regular play call rules. The box score reports book usage.

A dynasty snapshots the library at creation and assigns the computer books when the first season starts. Assignments are kept in the save. The user’s team keeps its own selected books.

All 39 focused tests passed. The integration test verified both the default and opt in paths, observed a custom offensive package selected in an all computer week, and verified that dynasty assignments survived a database reload.
