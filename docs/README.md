## Maintenance

Update the canonical reference when the feature changes. Preserve historical AARs; add a new dated report with revision, tests, measured evidence and open questions. Update DEVELOPMENT_PLAN.md for current status. Rule changes must reconcile README, RULES and engine tests. New statistics must name denominator, population, source and support. Documentation of an implementation is not evidence of deployment or validation.
