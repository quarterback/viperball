# Delta playbook implementation AAR
Implementation candidate; branch clinic/delta-special-teams, stacked on PR #399. See master_coaching_clinic_delta_special_situations_2026-11-27.md on main for source design.

All 20 catalog modules have live coarse selection policies: eight PP offense, eight PK defense, four backed-up offense. New engine/delta_playbook.py owns possession classification, per-module eligibility, contextual weights, front reads, retained-miss recognition, finish preferences and eight defensive posture/contest mappings. Game engine latches restart cost at new possession and preserves it across quarter boundaries; existing DYE statistics unchanged. Catalog vocabulary and installation now support Delta context. New coordinators with two available slots and compatible candidates reserve one situational slot within existing limits, not additional practice. Existing custom books and retained packages continue to govern installation. Defense commitments use existing rush count, alignment and contest costs; scoring drop kicks can trigger installed PK defense and a bounded block pressure adjustment. Selected PP finish modules can shift existing fourth/fifth-down kick thresholds by at most two yards; backed-up Territory Exit can shift existing sixth-down punt line by up to four yards, without removing the trailing-team punt gate. Package selection logged separately from actual action. Existing score, down, range, penalty, Delta and bonus rules remain.

Limitations: these are executable coarse engine policies, not full spatial formations, actual weak-side switches, defensive assignment exchanges, individual line changes or ordered multi-action progressions. Overload/Side Lock/Rotating Shell use existing family and commitment surfaces. Second Shot only triggers after an ordinary retained drop-kick miss with next down; existing kick-mode and red-zone gates take precedence. Rapid Finish uses selection and existing clock logic rather than a new tempo resolver. Coefficients are proposed and not fitted. No changes to player generation, injury rules, scoring, or new base schools. Existing practice growth and recruiting fit are reused; no new separate practice budget or adoption-rate evidence.
