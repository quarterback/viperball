# Progressive web app and site metadata — 2026-11-25

## Scope

The canonical Jinja/FastAPI site at /stats/ gains an installable standalone web app with a scoped service worker, manifest, install prompts and a branded offline fallback. Existing simulation and league management routes remain unchanged. The retired React app is not revived.

- Manifest: /stats/manifest.webmanifest; start URL and scope /stats/; college, dynasty, game simulator and saves shortcuts.
- Install icons: 192 and 512 PNG, including maskable icon; Apple touch icon 180 PNG; browser 32 PNG and ICO (also accessible from /favicon.ico).
- Shared HTML head: description, application name, page-specific social title, Open Graph and Twitter large-card metadata, absolute social-image URL on https://viperball.xyz.
- Social preview: 1200 x 630 PNG, existing orange/dark color palette, generic Viperball branding; images are rendered using the Python standard library without extra dependencies.
- Worker: caches only the offline page and install icons. Live navigations are network-first with no-store; no game HTML, API data, save files, POSTs or mutations are stored or queued. Existing server-side sessions remain authoritative.
- Install controls: native browser prompt where available; iOS instructions otherwise.

## Verification

Run pytest -q tests/test_stats_pwa.py. Test installed behavior on the HTTPS deployment with Chrome and Safari: install to home screen, reopen in standalone, navigate to a league, disconnect network, confirm offline fallback on navigation, reconnect and retry, verify game state remains current. Validate social card via actual URL unfurl. Browser installation, clipboard/preview behavior and production deployment are not verified by this change.

## Decisions and limitations

Scope is /stats/, not separate NiceGUI routes or API endpoints. No offline simulation, background synchronization, push notifications, or native app store packaging. The social card is shared across pages, while titles vary by page. The production social origin is viperball.xyz. Bump the worker cache version when changing precached assets.
