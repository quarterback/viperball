## AN-02 — Event contract v1

New game results contain analytics_before and analytics_resolution on real plays, plus analytics_contract_version and analytics_restart_baseline. These snapshots are observational; no RNG calls, game decisions, scores or clock changes. The finalized adapter engine/analytics_events.py:build_events(result, unique_game_id) emits stable game-scoped sequence IDs (not play_number, which is not guaranteed unique), explicit drive spans, score before/after, actual snap and resolution possession, next recorded state after the engine's transition/restart, clock, down, distance, field position, possession origin/id, penalty/nullification, Delta bucket and bonus context/provenance where observed. Synthetic overtime/bonus markers remain in the audit stream; terminal fallback kicks are tagged separately. Every score component comes from the existing BOX-01/02 scoreboard ledger, including half-points and compound return TD/bell. Unit, player label and bonus source are null if not established; no player ID is invented. Old games retain their scoreboard audit when possible but cannot supply the new state corpus. Missing state, inconsistent score and bad drive spans are explicit. Test gate fails rather than silently accepting an inconsistent corpus.

## EPA-02 — State value

The experimental model is version net-possession-exchange-v1. Target: signed net points from the current state through the current and next possession, stopping earlier at the end of a half or OT period. Same-side restarts count as distinct possessions; quarter fragments do not. The ball owner's perspective is positive; flip signs when possession changes. Learn both one- and two-possession continuation values so a fixed exchange telescopes: immediate signed reward + signed next-state value with remaining horizon - before-state value. Rolling two-possession estimates at each snap are descriptive aggregates, not a scoreboard-accounting identity.

The model fits play-weighted empirical cell means with hierarchical context pooling and game-clustered standard errors. No future score, result, or action is a feature. Context includes field, down, distance, margin, half/clock, restart origin, bonus recipient/wait/active state, school and pregame strength band when available. Coarser cells reduce context specificity; never pool across horizon or bonus state. Minimum support 30 observations and eight independent games per cell. Unsupported estimates are null. Holdout compares against the named legacy gross lookup minus a neutral opponent possession approximation (not an equivalent horizon model). Report coverage, bias, MAE, RMSE, predicted/observed means by down, field, scheme, scoring channel and support level. Predeclared candidate gate: >=75% coverage and matched MAE no worse than legacy comparator. Passing this gate alone does not authorize release.

## EPA-03 — Alternative decisions

Rules permit continue offense, drop kick, place kick and punt on ordinary downs. Nullified snaps, synthetic events and forced terminal kicks are not sampled as choices. At a common supported full/situation context level, compare observed action-conditional exchange outcomes. Return chosen value, value above continue (null when continue unsupported), supported-action regret, counts, game-clustered SE, and unsupported alternatives. These are observational and confounded by kicker, coach selection, roster, clock and unmeasured state; they are not causal cloned-state rollouts or player replacement value. Do not publish them as definitive counterfactual recommendations. Paired cloned-state studies remain an acceptance follow-up if causal estimates are required.

## EPA-04 — Restart decomposition

At a logged score restart, compare a neutral-baseline field with no bonus, actual field with no bonus, and actual bonus context at one common supported pooling level. Keep other recorded context fixed. Delta = middle - neutral; bonus context = actual - middle; residual reconciles to actual - neutral. Separately measure observed bonus-state contrasts. These are model-based conditional context estimates, not the causal value of creating an extra possession: an active bonus drive's ordinary-possession counterpart may not exist. Report unsupported cases rather than forcing a value. Actual points and context estimates are separate. Team and drive totals carry sample counts. No scoring or restart rule changes.

## DTW-02 — Recalibration and ablation

Existing 13-signal DTW and 55–45 band remain unchanged. Research module audits each legacy edge, then fits a symmetric regularized no-intercept retrospective outcome-alignment model on disjoint games using new EPA, turnover margin, stop rate, kick-pass completion and kicking efficiency. Compare removal of turnovers/EPA, inclusion of team rating, and inclusion of Delta/bonus context where available. Exclude quarter-win signal from candidate because it proxies scoreboard outcome. The fitted model still uses postgame information and is not a pregame probability or proof of deserving victory. Report held-out Brier/log loss, calibration, matched legacy scores and representative disagreements. No coefficient changes to public DTW.

## AN-03 — National baselines and reproducibility

Existing API dynasty harness collects each actual completed regular/playoff game into compressed JSONL with unique game ID, season, seed, game seed, event contract, observed scoreboard channels/units, weighted drive/Delta totals, bonus conversion, kick attempts and scheme/strength context. National jobs use two independent seeds; year one split by deterministic game ID hash into EP training and separate DTW training games, year two entirely held out. Standalone smoke holds out a separate seed range. Artifacts: corpus files, model.json, summary.json, heldout_games.json, including team/drive EPA, alternative examples, support counts, conditional Delta and bonus estimates, national totals/distributions and strata. All official totals reconcile. PR360 cross-revision baseline exports common observed score distributions for shared seeds and flags matching roster fingerprints; no equivalence asserted between old/new EPA or PPD definitions. This is a small matched historical reference, not a national PR360 replay.
