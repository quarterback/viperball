## AN-02 — Complete score and possession attribution
Inspect engine/game_engine.py, existing BOX-01 and drive/play logs before adding instrumentation. Publish a versioned event contract with game/drive/play/event IDs, sequence, clock, score before/after, possession before/after, field position/down, restart type, Delta bucket, bonus-possession provenance, scoring team, responsible unit and player when known, scoring channel and points. Represent unknown attribution explicitly. Handle all six scoring channels, defensive and interception/missed-kick returns, penalties, turnover on downs, changes of possession and terminal states. Avoid double counting return scores or assigning them to the originating offense. Keep raw events separate from derived metrics.
Acceptance: deterministic seeded fixtures for each channel and unusual transition; event sums reconcile exactly to scoreboard by team (including half points); drives and scoring buckets reconcile; no duplicated IDs; missing attribution reported; seeded gameplay traces unchanged. Deliver schema, adapter, fixtures and migration notes.

## EPA-02 — Empirical expected points
Replace the fixed lookup only after validation. Build a reproducible simulated-game corpus with seed, engine revision, roster/scheme strength, game/season ID, state and outcome labels. Specify perspective, horizon and terminal value before fitting: proposed primary target is net points from the current state through a defined possession exchange, including return scores and bonus entitlements; document exact stopping rules and avoid double counting future possession value. Define EPA as signed immediate reward plus continuation value minus pre-event value, with consistent team perspective across possession flips. Separate expected net points from gross offensive PPD and from win probability. Include down, position, score differential, clock, restart, personnel/opponent, scheme and bonus entitlement where support permits. Compare simpler lookup and fitted alternatives; handle sparse states with pooling or explicit unavailable estimates. No post-action leakage. Split by games/seasons/seeds, not random plays. Report sample counts, held-out bias, MAE/RMSE and calibration by state, scoring channel and scheme; propose thresholds against legacy baseline before evaluation. Publish model version, reproducible fit command, data schema and uncertainty/support flags. Retain old EPA in shadow comparison until integration. Acceptance: deterministic rebuild, correct sign/terminal handling, held-out evidence of improvement or documented failure, no fabricated estimates. Scoreboard reconciliation belongs to AN-02; EPA telescoping is tested only under its stated horizon and conventions.

## EPA-03 — Tactical alternatives / points above alternative
Define legal choices at the same pre-decision state (place kick, drop kick, continue offense and other legal options). Estimate expected net value for each using controlled cloned-state rollouts with matched seeds where feasible, or clearly qualified observational estimates; do not treat observed action averages as causal. Freeze roster, opponent, clock, field position, rules and continuation policy; include missed kicks, returns, turnover exposure and downstream scores. Record eligibility, rollout counts, uncertainty and policy version. Define chosen-action value minus a named baseline policy value, and decision regret as best supported legal action minus chosen value. Keep realized execution separate from expected decision quality. Player replacement value is out of scope. Acceptance: no illegal alternatives, reproducible matched comparisons, uncertainty/support thresholds, tests of ties and sparse situations, no production AI playcalling changes. Validate against independent seeds before display.

## EPA-04 — Bonus and Delta value
Use the shared state-value interface to estimate bonus entitlement value and possession-transfer cost. Separate value at restart from subsequent execution; compare actual Delta restart to a documented neutral reference state with other factors held fixed when feasible. Keep observed points distinct from counterfactual estimates. Do not alter restart rules. Establish an explicit decomposition order or interaction residual so overlapping bonus/Delta/return effects cannot be counted twice; report when counterfactual states lack support. Acceptance: paired seeded comparisons for leaders/trailers, neutral and bonus states, turnover on downs and defensive returns; components reconcile to the defined value difference; no causal claims from unadjusted PPD. Publish team/drive aggregates with denominators and uncertainty.

## DTW-02 — Recalibrate deserved-to-win
Audit all 13 existing signals, team rating contribution, signed components and missing direct turnover margin in engine/dtw.py. Determine whether DTW is a descriptive performance index or a retrospective win-probability estimate; retain distinct labels and do not equate winning with deserving. Compare old model, corrected EPA, turnover/possession value, defensive and special-teams effects using held-out games and ablations; guard against double counting correlated inputs, scoreboard leakage and strong-team prior bias. If fitting win probability, report Brier/log loss and calibration; for descriptive DTW also review representative close games, upsets and disagreements with outcomes. Preserve 55–45 classification until evidence supports change and document any change separately. Acceptance: symmetry under team swap, equal-signal no-upset case, component reconciliation, stable held-out evidence, clear explanation of disagreements. Do not change game engine decisions.
